## Primary blockers

1. Replace generic swim with a reach-and-retrieve pose tied to the active memory.
2. Add an authored close camera insert for keeper hand / glowing relic / memory shell contact.
3. Build textured torn sail, wood grain, barnacle and paper-fibre surfaces for the wreck.
4. Add surface refraction, descending light shafts and distance haze to create convincing depth.
5. Reduce bubble/silt/current counts on low quality tier.
