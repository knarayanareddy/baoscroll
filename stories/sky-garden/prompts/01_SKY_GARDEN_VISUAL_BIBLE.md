# Phase 1 prompt — Seeds of the Sky Garden visual bible

## Instruction

> Build the complete **Seeds of the Sky Garden visual bible** before any runtime scene code is authored. Use `stories/sky-garden/SKY_GARDEN_PRODUCTION_PLAN.md`, especially Phases 1 and the review rubric, as the non-negotiable completion contract. Create an original Gardener action sheet, sentient Watering Can narrator sheet, seed/plant behavior sheet, material board, six cinematic chapter keyframes, and chapter camera/beat boards. Review all work for continuity, action clarity, material hierarchy, scale, and Bao-level depth. Do not start Phase 2 foundation code until every visual-bible success criterion is met or explicitly rejected with evidence.

# 1. Visual target

## One-sentence art statement

> A tiny caretaker tends a tactile sky garden made of pastel watercolor cloud, felt flowers, tissue-paper sunlight, kite cloth, translucent rain beads, and living vines—small acts of care restoring rain to a world below.

## Required depth rule

Every keyframe must contain:

```text
foreground touch point
→ hero action midground
→ layered narrative background
→ visible material state
→ a clear route or obstacle
```

No keyframe may be only:

```text
floating islands
+ pastel sky
+ decorative flowers
```

## Prohibitions

```text
generic fantasy-cloud wallpaper
photorealistic skies
plastic 3D flowers
random rainbow color overload
unreadable clutter
copied Bao/Lighthouse/Erdtree imagery
text, logos, watermarks
```

# 3. Gardener design criteria

## Required identity

The gardener must be recognizable in silhouette before colour is read:

```text
small rounded rain cape
soft work boots
seed satchel
watering tool / can handle
cloud-fibre hair or hood
visible plant/tendril interaction posture
```

## Required design views

```text
front
three-quarter
profile
back
```

## Required action studies

```text
walk nursery bed
water a seed
plant seed
guide vine
hold kite grip
run/float on moving island
climb orchard branch
catch thunder fruit
shield seed from sun
open cloud reservoir valve
watch rain fall
```

## Design QA

- [ ] Silhouette remains legible at city-wide / island-wide camera scale.
- [ ] Costume has no generic wizard/elf/fairy cues.
- [ ] Satchel, watering tool, and seed language are visible in every key action.
- [ ] Gardener feels practical and caring, not overly cute or passive.

---

# 4. Watering Can narrator design criteria

The watering can is a narrator/companion, not comic relief.

## Required identity

```text
weathered copper or painted tin body
warm rain-drop eye/light
small spout that can point/gesture
handle silhouette
subtle cloud condensation detail
```

## Required states

```text
quiet observer
concerned during Dry Sun state
encouraging during growth
ringing with thunder rain
softly reflective at finale
```

## QA

- [ ] Can reads as a distinct narrator, not a random garden prop.
- [ ] Its material language fits brass/tin/rain rather than Lighthouse brass.
- [ ] It can appear as small guide without replacing Gardener agency.

# 5. Seed and plant behavior sheet

Create a sheet defining six impossible seeds and their runtime material behavior.

| Seed | Chapter | Growth behavior | Material meaning |
|---|---|---|---|
| Root seed | I/II | segmented vine bridge | green felt/fibre continuity |
| Kite seed | III | fabric leaf/kite anchors | wind and route reading |
| Thunder seed | IV | fruit stores lightning/rain | storm held gently |
| Canopy seed | V | broad translucent shade leaf | care against heat |

## QA

- [ ] Each seed can be recognized by silhouette/material at a glance.
- [ ] Each has a specific growth/contact state, not a generic “flower grows” effect.
- [ ] Each behavior is reversible with local scroll progress.

# 6. Material board criteria

Required material classes:

```text
pastel watercolor cloud wash
felt/fibre leaves and flowers
tissue-paper sunlight
kite cloth
wet cloud soil
translucent rain beads
pollen
thunder fruit
heat-thread/sun ray
rain-darkened world below
```

## Color hierarchy

| Material | Meaning |
|---|---|
| Cream / pale blue | cloud body / nursery calm |
| Soft green | living growth / vine continuity |
| Coral / red | seed vitality / route warning, used sparingly |
| Gold | thunder fruit / warm rain energy, not generic decoration |
| Ink blue / violet | dry storm / wind / distant world |
| Peach / butter yellow | softened sun / resolved dawn |

## QA

- [ ] The Dry Sun uses bleach/heat-thread behavior, not only yellow overlay.
- [ ] Rain has bead, streak, wash, and ground-response states.
- [ ] Materials clearly differentiate dry, watered, storm-charged, and restored plant states.

# 7. Six keyframe criteria

## I. Dry Cloud Nursery

```text
foreground: cracked cloud soil / empty water cup
midground: Gardener discovers seed satchel and waters first seed
background: thinning cloud reservoir, dry world below
```

**Required read:** something living is running out, but care has begun.

## II. First Seed

```text
foreground: vine segment growing over void
midground: Gardener guiding/watering bridge
background: next island and impossible drop
```

**Required read:** bridge is being grown while crossed.

## III. Wind Maze

```text
foreground: kite cloth / wind ribbon
midground: Gardener holding a grip on moving island
background: maze layers and thunder orchard gate
```

**Required read:** wind is route and obstacle.

## IV. Thunder Orchard

```text
foreground: branch/fruit contact
midground: Gardener catches thunder fruit
background: vertical orchard / storm reservoir
```

**Required read:** storm is being harvested, not defeated.

## V. Garden Meets the Sun

```text
foreground: bleaching heat thread / canopy edge
midground: Gardener planting final seed under direct sun
background: huge soft sun terrace and drying clouds
```

**Required read:** gardener asks the sun to soften, not disappear.

## VI. Rain Returns

```text
foreground: open reservoir valve / first rain bead
midground: Gardener watches restored garden
background: rain reaches world below
```

**Required read:** rain is a consequence of all prior care.

# 9. Bao-level Phase 1 success rubric

Phase 1 passes only if every keyframe scores 4/5 or better across:

| Lens | Required check |
|---|---|
| Hero | Gardener action/silhouette readable instantly |
| Contact | Key object/plant/weather contact is visible |
| Space | Foreground, action midground, and depth layers read |
| Material | Cloud/felt/paper/rain/sun states are specific |
| Story | Objective/obstacle/consequence are legible |
| Continuity | Gardener, can, seeds, colors, and route motifs remain consistent |
| Production | Frame can be decomposed into real runtime layers and assets |

## Phase 1 final gate

Do not write Sky Garden production code until:

- [ ] Gardener and watering-can designs are approved.
- [ ] All six seeds have defined material/contact behavior.
- [ ] Six keyframes pass visual continuity review.
- [ ] Every chapter has four camera/beat boards.
- [ ] Runtime layer decomposition exists for each keyframe.
- [ ] Any rejected/keyframe continuity issue is corrected, not merely documented.
